# Untitled-Run-n-Gun
Untitled Run 'n Gun game with Metal Slug assets. My biggest project. Doing it in C++ and raylib.
The game is in active development.

# My targets
First of all, I like Metal Slug series. I just enjoy cool graphics and SFX.
One day I wanted to create such a game myself, so I started.

The game will contain classic arcade mode and online multiplayer (will be added much later). I don't wanna remake classic Metal Slug games, so it will be filled with my own levels.

# Why is the game untittled?
I didn't give a title, because I don't want to make just a Metal Slug fun-made game. I want it to be independent. I use assets from Metal Slug only becasue I find them outstanding.
